## 1.2.0
- Add compatibility with [Fast Item Frames](https://modrinth.com/mod/fast-item-frames) by [Fusz](https://modrinth.com/user/Fusz)
  - This compatibility includes:
    - Item Frame variants can be dyed like leather
    - Item Frame variants get rendered as blocks (better performance)
      - (This doesn't prevent multiple item frames from being placed in the same block space)
    - Item Frame variants drop and can be pick-blocked as the correct variant with the dye data saved
    - Item Frame variants can be undyed with a cauldron
- Add compatibility with several painting mods
  - This includes:
    - [Macaw's Paintings](https://modrinth.com/mod/macaws-paintings)
    - [Dark Paintings](https://modrinth.com/mod/dark-paintings) by Darkhax
    - [Nemo's Paintings](https://modrinth.com/mod/nemos-paintings)
- Fix Item Frame variant item textures missing the hanging wire of the vanilla texture
