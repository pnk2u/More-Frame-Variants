- - **[Fast Item Frames](https://modrinth.com/mod/fast-item-frames)** _by [Fusz](https://modrinth.com/user/Fusz)_  
    Compatibility features include:
    - Item Frame _variants_ can be **dyed** like leather
    - _Variants_ are rendered as blocks for **improved performance**
    > Note: This does not prevent multiple frames from being placed in the same block space
    - Dyed _variants_ drop and can be pick-blocked with dye data preserved
    - _Variants_ can be undyed using a cauldron
    - `1.20.1`: Fixed a bug in FIF where only the first placed Item Frame in a block position would display its dyed color
- Fix missing hanging wire on Item Frame variant item textures
